
# Python Age Calculator

## Project Overview
The Python Age Calculator is a simple command-line application that calculates a person's exact age in years, months, and days based on their date of birth.

It uses Python's built-in datetime and calendar modules to perform accurate date calculations.

## Features
- Calculates exact age in years, months, and days.
- Handles leap years.
- Supports different month lengths.
- Validates date of birth.
- Prevents future dates.
- Handles invalid inputs using try-except.
- Simple command-line interface.

## Technologies Used
- Python 3
- datetime module
- calendar module

## Requirements
- Python 3.x
- Any Python IDE (VS Code, IDLE, PyCharm) or terminal.

No external libraries are required.

## How to Run the Program

1. Download or clone this repository.
2. Open the project folder.
3. Open the terminal.
4. Run the following command:

```bash
python age_calculator.py
```

5. Enter your date of birth in DD-MM-YYYY format.

## Sample Output

```text
===== AGE CALCULATOR =====

Enter your date of birth (DD-MM-YYYY): 15-08-2000

Your exact age is:
Years : 26
Months: 2
Days  : 20
```

## Error Handling

The application handles:
- Invalid date formats.
- Invalid calendar dates.
- Future dates of birth.
